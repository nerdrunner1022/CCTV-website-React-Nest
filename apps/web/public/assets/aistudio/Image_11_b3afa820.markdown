## Brand & Style

This design system expresses a high-assurance, tactical, and uncompromisingly modern visual language tailored for mission-critical surveillance, perimeter telemetry, and enterprise-grade physical security infrastructure. The design identity merges engineering precision with operational authority. It communicates impenetrable defense, zero-latency situational awareness, and algorithmic intelligence.

The visual style combines technical minimalism with tactical HUD and glassmorphic overlays. Interfaces lean into deep obsidian and midnight slate substrates punctuated by focused luminescent accents: electric cyber-cyan for primary actions and targeting vectors, operational cobalt for structural utilities, and vivid status emerald for verified integrity. Structural elements utilize subtle technical grids, hairline framing borders, sub-millimeter visual calipers, and monospaced telemetry readouts to establish an operational control-room atmosphere without unnecessary clutter.

## Colors

The palette is engineered specifically for low-light command center environments and high-density technical analysis:

- **Substrates & Surfaces:**
  - Base Obsidian Canvas: `#0B0F17` (Deepest canvas layer).
  - Slate Tier 1 Surface: `#111827` (Paneling, secondary cards, base chrome).
  - Slate Tier 2 Surface: `#1F2937` (Hover states, elevated module wells, active borders).
  - Surface Glass: `rgba(17, 24, 39, 0.75)` with backdrop filter for HUD overlays and floating panels.

- **Primary & Operational Accents:**
  - Cyber Cyan (`#06B6D4`): Used for primary interactive triggers, active optical reticles, primary system focal points, and live beam indicators.
  - Electric Blue (`#3B82F6`): Used for secondary navigation, analytical links, data streams, and operational states.
  - Emerald Verified (`#10B981`): Dedicated strictly to encrypted streams, armed sensors, positive telemetry, and active recording pulses.

- **Status & Warning Accents:**
  - Critical Alert Amber: `#F59E0B` (Tamper warnings, motion triggers).
  - High Breach Red: `#EF4444` (Signal loss, unauthorized intrusion, hardware fault).

- **Technical Text & Borders:**
  - Primary Readout: `#F9FAFB` (High legibility, headers, focal metrics).
  - Secondary Readout: `#9CA3AF` (Supporting metadata, labels).
  - Hairline Frame Border: `rgba(255, 255, 255, 0.08)` and active cyber border `rgba(6, 182, 212, 0.4)`.

## Typography

The typographic hierarchy implements a bifurcated structure: an authoritative, geometric sans-serif (`Plus Jakarta Sans`) for primary communication, value propositions, and navigation; paired with a high-performance monospace typeface (`JetBrains Mono`) for all hardware telemetry, status badges, specs, resolution coordinates, and technical configurations.

Headings maintain razor-sharp clarity with slight negative letter tracking to convey solid industrial density. Monospaced elements are systematically capitalized and letter-spaced to reflect instrument panels, IP protocols, sensor IDs, and hardware runtimes.

## Layout & Spacing

The layout is built upon an adaptive 12-column surveillance grid model calibrated to support dense real-time telemetric streams alongside marketing narratives:

- **Desktop (1280px+):** 12 columns, 1.5rem gutters, 3rem canvas edge margins. Maximum container width capped at 1440px to retain cockpit-like density.
- **Tablet (768px – 1279px):** 8 columns, 1rem gutters, 2rem canvas margins. Multi-column sensor matrices collapse to dual-column telemetry blocks.
- **Mobile (<768px):** 4 columns, 0.75rem gutters, 1rem canvas margins. Grid collapses into vertical sensor stacks, pinned floating actions, and horizontally scrollable spec carousels.

Spacing rhythms strictly adhere to an 8px base grid (0.5rem intervals). Tight element clustering (`space-xs` to `space-sm`) is enforced within telemetric modules, data tables, and sensor indicators to reinforce high-density engineering, while section-level separation relies on `space-xl` coupled with hairline grid separator lines.

## Elevation & Depth

Visual hierarchy does not rely on traditional dropped shadows; instead, depth is created through **translucent glass layers, luminous edge diffusions, and low-contrast hairline borders**:

- **Layer 0 (Canvas Base):** Solid Obsidian (`#0B0F17`) featuring subtle engineering gridlines (`rgba(255, 255, 255, 0.02)` at 32px increments) and focal radial gradient vignettes behind active hardware heroes.
- **Layer 1 (Modular Surfaces & Panels):** Slate Tier 1 (`#111827`) with a 1px crisp outer border (`rgba(255, 255, 255, 0.07)`). Zero shadow.
- **Layer 2 (Floating Overlays, HUDs & Tooltips):** Frosted glass panels using `rgba(17, 24, 39, 0.8)` with a 12px backdrop blur, bordered by `rgba(6, 182, 212, 0.25)`.
- **Layer 3 (Focused & Active Reticles):** Hardware modules in an engaged state generate a controlled, low-spread cyan photoluminescence: `box-shadow: 0 0 24px rgba(6, 182, 212, 0.18), inset 0 0 12px rgba(6, 182, 212, 0.08)`.

## Shapes

The shape vocabulary employs **Level 1 (Soft)** rounding (0.25rem / 4px base border radius) with selective chamfered and sharp corners. This maintains an architectural, tactical hardware silhouette while remaining clean and ergonomically sound for modern interactive surfaces.

Cards and modular panels utilize a strict 4px radius (`rounded-sm`). Small chips, status tags, and telemetry badges employ 2px radius or sharp 0px corners to evoke machine-stamped data tags. Surveillance reticles, crosshair brackets, and telemetry overlays use square 90-degree corner trims. High-contrast primary CTA buttons maintain the disciplined 4px radius; pill shapes are strictly excluded to avoid consumer-toy aesthetics.

## Components

### Buttons
- **Primary Cyber Action:** Background `#06B6D4` with `#0B0F17` ultra-bold text (`Plus Jakarta Sans` 600). 4px border radius. Hover introduces a high-luminance Cyan glow (`0 0 16px rgba(6, 182, 212, 0.45)`) and slight upward translation.
- **Secondary System Action:** Background `rgba(17, 24, 39, 0.85)` with a 1px border of `rgba(255, 255, 255, 0.15)` and `#F9FAFB` text. Hover shifts border color to `#3B82F6` and applies a subtle slate highlight.
- **Tactical Ghost Action:** Transparent background, `JetBrains Mono` text in `#06B6D4`, flanked by subtle HUD brackets (`[ RUN DIAGNOSTIC ]`).

### Badges & Technical Specification Chips
- Rendered in `JetBrains Mono` (10px or 12px uppercase).
- Structured with a dark inset background (`rgba(0, 0, 0, 0.5)`), a 1px boundary (`rgba(255, 255, 255, 0.1)`), and an integrated status dot.
- Verified state features an Emerald pulse indicator (`#10B981` with a CSS breathing ping).

### Input Fields & Selectors
- Solid `#0F172A` background encased in a 1px `rgba(255, 255, 255, 0.1)` border.
- Active/focused state snaps the border to `#06B6D4` accompanied by a micro inner shadow.
- Placeholder text set in `#6B7280`. Input labels rendered in uppercase `JetBrains Mono` with technical field numbering (e.g., `01 // STREAM_SOURCE_IP`).

### Cards & Surveillance Nodes
- Constructed with Slate Tier 1 (`#111827`) fill, 1px perimeter framing in `rgba(255, 255, 255, 0.08)`, and a 4px corner radius.
- Cards feature optional top-right optical target icons or coordinate markers (`LAT/LONG` or `CH-04 // 4K 60FPS`).
- Interactive card states highlight the boundary line to `rgba(6, 182, 212, 0.5)` with an instant 120ms transition.

### Checkboxes & Radios
- Crisp 2px rounded squares for checkboxes; sharp octagonal or circular frames for radios.
- Unchecked: `#111827` surface with `rgba(255, 255, 255, 0.2)` border.
- Checked: `#06B6D4` solid fill with a pitch-black obsidian checkmark icon or center reticle dot.

### Surveillance Grid & Video Feed Frames
- 16:9 ratio containers fitted with frosted HUD overlays, top-left camera identification stamps (`CAM_08_PERIMETER_NORTH`), top-right live timestamps in `JetBrains Mono`, and bottom optical telemetry readouts (Bitrate, Codec H.265, FPS counter).
